# Dados de treinamento do Proton-AI

O diretório contém apenas dados de demonstração versionados. Antes de adicionar qualquer corpus, registrar:

- título e descrição do conjunto;
- URL/origem e data de obtenção;
- licença ou permissão explícita de uso para treinamento;
- idiomas e assuntos;
- método de limpeza e deduplicação;
- divisão treino/validação/teste por documento;
- responsável e data da revisão.

Não incluir conteúdo privado, credenciais, dados pessoais, material protegido sem autorização, nem dumps indiscriminados da internet. Não tratar respostas geradas pelo próprio Proton como fatos confiáveis sem verificação independente.

`data/starter.txt` é apenas um corpus minúsculo para verificar o pipeline; não é suficiente para ensinar conhecimento amplo. Aumentar o arquivo repetindo frases não cria conhecimento novo.

O diretório `data/` pode conter dados locais ignorados pelo Git. Para dados públicos versionados, documentar licença e origem em um manifesto separado antes de adicioná-los ao repositório.
